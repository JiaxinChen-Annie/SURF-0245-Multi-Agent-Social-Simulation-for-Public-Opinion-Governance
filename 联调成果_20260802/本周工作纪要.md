## 本周 ABCDE 分别干了什么

**A 干了：**  
合入联调底座（opinion/types/agent/event 与 mesa 相关配置）；落地负面阈值干预、MUTE/ANNOUNCE、分层转发门控与 GROUP_EXPOSURE；完善 SimClock（`tick_seconds` / `place` / `time_slot`）；区分 `governance_tick` 与 `intervention_tick`；联调侧保留并衔接 C 的 Hawkes 引擎与 `run_sim` 元信息（如 `step_seconds`、`run_meta.json`）。

**B 干了：**  
将记忆系统并入与 A 枚举兼容的 `social_agent`（未直接替换会破坏接口的独立枚举版）；实现短期记忆、长期摘要、高冲击记忆与信任微衰减；感知与记忆分离；向 LLM `env_info` 提供 `memory_summary` / `trust`；与 C 的预算截断、`user_id` 等调用约定共存。

**C 干了：**  
优化 `llm_utils`（`max_tokens`、json_mode、关闭思考链、提示词/记忆/近期消息上限、并发信号量、`user_id=agent-{id}`、用量统计）；锁定并微调 `config_100_ds` 预算参数；完成短窗 vs 松散提示的对照实验；修复 FORWARD 被 ANNOUNCE 淹没导致跨组转发接近 0 的问题；主跑侧恢复可观的跨组转发与通道分流统计。

**D 干了：**  
合入/对齐 `strategy_eval`、ABC 适配器与 D→ABC 集成脚本；评估按 `governance_tick`、滚动窗口、GroupType/AgentType 切片与 `time_profile` 输出；保证评估读取字段与联调宽表一致。

**E 干了：**  
针对宽表 `metrics.csv` 改进出图脚本；新增按 AgentType（fig7）、GroupType（fig8）的分层可视化；DataCollector 增加 `avg_opinion_*`、`neg_emotion_*`、`group_heat_*`、`group_neg_*` 等列；完成 mock 全流程出图与真 LLM 结果归档。

## 本周有什么优化（相对上周）

1. **验收从失败到通过**：上周对照 `run_meta` 为 `all_pass: false`；本周主跑 100×20 为 `all_pass: true`。  
2. **跨组扩散显著增强**：`cross_group_forward` 由约 29 提升到约 1194（主跑），并具备组内/上向/横向/下向通道统计。  
3. **LLM 更稳更快**：提示预算与并发控制，减少超时与无效长 prompt；动作解析对 MUTE/ANNOUNCE/FORWARD 更可控。  
4. **模块可复现合入**：不再“各写各的接口”；记忆、治理节拍、评估窗口、报表列在同一联调树上对齐。  
5. **结果可解释性增强**：`run_meta` 更丰富；报表支持角色/群体切片，便于写周报与答辩材料。

- **Mock**：100 智能体 × 50 步，规则桩全流程冒烟通过（消息量偏低属规则 stub 特性，不作真实传播基线）。
