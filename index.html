6. 演化曲线（tick 0–19）

平均观点 avg_opinion

Y: 观点均值 ∈ [-1, 1] · X: 仿真步 tick

构成含义

纵轴是全体 agent 对主话题观点的算术平均：−1 强烈反对，0 中立，+1 强烈支持。两条曲线分别是 Mock 与 DeepSeek 在相同种子下的时序。

数据解读

Mock 全程钉在约 +0.043，说明 MockLLM 几乎不改信念。DeepSeek 由约 +0.024 很快转为负值，末态约 −0.053：均值仍接近零，但已出现可观测的轻微负向漂移，证明真 LLM 路径在更新观点。

观点极化 polarization

Y: 观点标准差（极化程度） · X: tick

构成含义

纵轴是观点分布的标准差。数值越高，群体内部意见越分裂（有人很正、有人很负），不等于“全体都更负面”。

数据解读

Mock 钉在约 0.60。DeepSeek 由约 0.64 持续升至约 0.96：结合上图均值几乎贴零，说明不是一边倒共识，而是两极分化加剧。这是真 Key 相对 Mock 最显著的差异之一。

负面情绪占比 negative_emotion

Y: valence < 0 的 agent 比例 · X: tick

构成含义

统计 valence（情绪效价）小于 0 的 agent 占总人数比例。反映“有多少人处于偏负情绪”，不是观点均值本身。

数据解读

Mock 仅从 0.49 缓升到约 0.58。DeepSeek 从 0.49 升到约 0.87，即近九成 agent 情绪偏负。提示 LLM 的 emotion_delta 偏负较强；写报告时应区分“情绪负面”与“观点共识”。

近窗消息量 message_count

Y: 信息流近窗长度（非累计） · X: tick

构成含义

纵轴是环境信息流缓存中当前仍有效的消息条数（有过期淘汰），不是从开局到现在的累计发帖总量。上升表示讨论变活跃，回落常因旧消息过期。

数据解读

早期两条曲线接近（如 tick0 都是 4）。随后都先升后略降：Mock 峰约 162、tick19 约 151；DeepSeek 峰约 138、tick19 约 111。说明传播层骨架相似，DeepSeek 并未额外制造“消息爆炸”，差异更多在认知—情绪层。

跨群累计 cross_group_forward

两条实验在 seed=42 下完全重合（热度溅射代理）

构成含义

指标名含“转发”，但当前实现里该累计值主要来自：某群热度 H≥θ 后，按概率把热度溅射到其他群并 +1。不是“某个 agent 把消息发到另一群”的微观转发次数。

数据解读

Mock 与 DeepSeek 在 tick 0–19 逐点相同（2→29），因为同种子下环境热度溅射的随机过程一致，与 LLM 几乎无关。因此它能证明“跨群热度溢出机制在跑”，不能单独当作多层群聊真实转发链的证据。Mock 若跑满 50 步，该值会继续累加到约 94。

近窗失真 distortion_level

Y: 近窗失真均值 · X: tick

构成含义

对信息流中最近若干条消息的 distortion_level 取平均。forward / paraphrase / exaggerate 等消息类型会抬高失真；clarification 通常较低。

数据解读

Mock 长期接近 0–0.01。DeepSeek 中段出现尖峰（约 tick10–11 达 0.11 左右），末态约 0.07，整体仍不高。说明真模型路径下偶发更高失真内容，但尚未形成持续高失真主导。

每步耗时 step_seconds

Y: 秒 · 注意两侧量级差三个数量级

构成含义

每一仿真步的墙钟耗时（秒）。反映该步内调度、agent 决策（含可能的 API 调用）与数据采集的总成本。

数据解读

Mock 约 0.01–0.02 秒/步，几乎贴零轴。DeepSeek 第 0 步约 34 秒，其后稳定在约 82–96 秒/步，总时长约 28 分钟。量级差来自同步调用 DeepSeek API，属于预期成本，不能用 Mock 的“<30 秒验收”去否定真 Key 实验。

结果分析

联调骨架已验证：两类实验均完整产出指标且无 NaN。Mock 适合秒级验收；DeepSeek 证明真实 LLM 可改变信念与情绪。

Mock 观点/极化全程钉死；DeepSeek 极化与负面情绪明显上升——差异主要在认知—情绪层，消息活跃形态仍相近。

跨群注意：tick 0–19 的 cross_group_forward 逐点相同，当前实现主要是热度溅射计数，不是「一人把消息转到另一群」的微观转发链。

结论

  • 100 agent 规模下 ABCDE 联调可稳定跑通；
  • DeepSeek 在约 28 分钟 / 20 步下产生可观测演化；
  • 大模型主要拉动认知—情绪层；跨群微观机制仍待补强。
